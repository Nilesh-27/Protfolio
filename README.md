# Nilesh Dokuparthi — Portfolio

A responsive, dark-theme portfolio for backend development, cloud engineering, DevOps, and application security roles in Germany. Built with static HTML and CSS; no build step or JavaScript framework is required.

## Preview locally

Open `index.html` in a browser. Keep `styles.css` in the same directory.

## Enable GitHub Pages

1. Open [repository settings](https://github.com/Nilesh-27/Protfolio/settings/pages).
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the deployment to finish. The expected URL is https://nilesh-27.github.io/Protfolio/.
